# 🛡️ Smart Sentinel

## 📖 Overview
Smart Sentinel is an AI-powered safety monitoring system designed to detect emergencies and send instant alerts to predefined contacts. It analyzes user input and location data to identify potential risks and ensures quick response during critical situations.

## ✨ Key Features
- 🔍 **Real-time monitoring** of user messages and activity
- 🚀 **Automated emergency alerts** via WhatsApp integration
- ⚙️ **Location-based risk detection** using geolocation services
- 🧠 **Basic sentiment analysis** to identify distress signals

## 🛠️ Tech Stack
- **Language:** Python
- **Tools & Libraries:** Flask, Twilio API, MongoDB, Geopy, TextBlob
